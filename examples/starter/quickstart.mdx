## Install

<CodeGroup>

```bash npx
npx papervine@latest dev
```

```bash global
npm i -g papervine
papervine dev
```

</CodeGroup>

Requires Node 20.9 or newer.

## Point it at your docs

Run it inside any folder that has a `docs.json` at its root. Docs usually live in a
subdirectory, so pass the path:

```bash
papervine dev ./docs
```

<Tip>
  Coming from Mintlify? There's nothing to migrate — the same `docs.json` and the same MDX
  render as-is. Clone your existing docs repo and point the CLI at it.
</Tip>

## Frontmatter

Every page takes a `title` and a `description`:

```mdx
---
title: Your page
description: One line that shows under the heading and in search results.
---

Your content here.
```

## Navigation

Pages appear in the sidebar because `docs.json` lists them. A page that isn't in the
navigation still renders at its URL — it just isn't linked:

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [{ "group": "Get started", "pages": ["index", "quickstart"] }]
      }
    ]
  }
}
```

Group names are labels; the strings in `pages` are file paths without the extension, so
`"guides/setup"` is `guides/setup.mdx`.
