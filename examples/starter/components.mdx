Everything here works in any `.mdx` page with **no imports**. Each page shows the component
rendered, then the exact source that produced it — hover a code block to copy it.

<Note>
  An unrecognized component degrades to its children rather than breaking the page, so an
  unsupported feature never takes a page down.
</Note>
