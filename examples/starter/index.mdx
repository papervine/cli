This folder is a complete, working docs site: a `docs.json` and a few MDX pages. Nothing
else is required.

Preview it from the repository root:

```bash
npm run dev -- examples/starter
```

Or, with the published CLI, from anywhere:

```bash
npx papervine dev
```

<Note>
  Every page renders per request and is read from disk, so save a file and refresh to see
  the change.
</Note>

## Make it yours

<Steps>
  <Step title="Copy the folder">
    Copy `examples/starter` to wherever your docs should live, or start from it in a fresh
    repository.
  </Step>
  <Step title="Edit docs.json">
    Set `name`, pick your `colors`, and lay out the `navigation` tree. Every page in the
    tree is a `.mdx` file at the matching path.
  </Step>
  <Step title="Write pages">
    Add `.mdx` files with `title` and `description` frontmatter, then reference them from
    the navigation.
  </Step>
</Steps>
