Use a tooltip for a term you don't want to interrupt the sentence to define.

Hover or focus a term for a definition: <Tooltip headline="MDX" tip="Markdown with JSX components mixed in — the format these pages are written in." cta="See the quickstart" href="/quickstart">MDX</Tooltip>.

```mdx
Hover or focus a term for a definition: <Tooltip headline="MDX" tip="Markdown with JSX components mixed in — the format these pages are written in." cta="See the quickstart" href="/quickstart">MDX</Tooltip>.
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tip` | `string` | required | The tooltip body. |
| `headline` | `string` | — | Bold heading inside the tooltip. |
| `cta` | `string` | — | Link text. |
| `href` | `string` | — | Link target for the `cta`. |
