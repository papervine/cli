---
title: "Badges"
description: "Inline status labels for versions, stability and deprecation."
---

Badges sit inline with text, so they work in headings, table cells and prose.

Status: <Badge color="green">Stable</Badge> <Badge color="yellow">Beta</Badge> <Badge color="red">Deprecated</Badge>

<Badge icon="star" color="blue" size="lg" shape="pill">Premium</Badge> <Badge color="gray" stroke>Outlined</Badge>

```mdx
Status: <Badge color="green">Stable</Badge> <Badge color="yellow">Beta</Badge> <Badge color="red">Deprecated</Badge>

<Badge icon="star" color="blue" size="lg" shape="pill">Premium</Badge> <Badge color="gray" stroke>Outlined</Badge>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `string` | `gray` | Any named colour or CSS colour. |
| `size` | `string` | `md` | `sm`, `md` or `lg`. |
| `shape` | `"rounded" \| "pill"` | `rounded` | Corner style. |
| `icon` | `string` | — | A Lucide icon name shown before the label. |
| `stroke` | `boolean` | `false` | Outline instead of a filled background. |
| `disabled` | `boolean` | `false` | Muted styling. |
