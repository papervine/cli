title: "Prompts"
description: "A copyable AI prompt, with an optional editor hand-off."
---

Use a prompt block to hand readers a ready-made instruction for an assistant.

<Prompt description="Ask an assistant to draft a page in this project's voice." icon="sparkles" actions={["copy", "cursor"]}>
Write a new docs page describing the feature I just built. Match the tone of the existing pages, keep it task-focused, and use the components from /components where they help.
</Prompt>

```mdx
<Prompt description="Ask an assistant to draft a page in this project's voice." icon="sparkles" actions={["copy", "cursor"]}>
Write a new docs page describing the feature I just built. Match the tone of the existing pages, keep it task-focused, and use the components from /components where they help.
</Prompt>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `description` | `string` | — | Shown above the prompt text. |
| `icon` | `string` | — | A Lucide icon name. |
| `actions` | `string[]` | — | Buttons to show, e.g. `["copy", "cursor"]`. |
