---
title: "Code groups"
description: "Several code blocks as one tabbed panel."
---

Use a code group for the same instruction in different tools or languages. The tab label comes from each fence's title.

<CodeGroup>

```bash npm
npm i papervine
```

```bash pnpm
pnpm add papervine
```

```bash yarn
yarn add papervine
```

</CodeGroup>

<Note>
  Give every fence in a group a title. Untitled fences fall back to the language name, which
  is unhelpful when they all share one.
</Note>
