---
title: "Accordions"
description: "Collapsible sections for FAQs and detail that would crowd the page."
---

Wrap `<Accordion>` entries in an `<AccordionGroup>` to stack them with shared borders. Each one collapses by default.

<AccordionGroup>
  <Accordion title="Collapsed by default">
    Good for FAQs and detail that would otherwise crowd the page.
  </Accordion>
  <Accordion title="Open on load" defaultOpen>
    Pass `defaultOpen` to start expanded.
  </Accordion>
</AccordionGroup>

```mdx
<AccordionGroup>
  <Accordion title="Collapsed by default">
    Good for FAQs and detail that would otherwise crowd the page.
  </Accordion>
  <Accordion title="Open on load" defaultOpen>
    Pass `defaultOpen` to start expanded.
  </Accordion>
</AccordionGroup>
```

An accordion can hold any content, including code blocks and other components.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` | required | The clickable heading. |
| `defaultOpen` | `boolean` | `false` | Start expanded. |
