---
title: "Visibility"
description: "Content for humans or for AI agents only."
---

`for="agents"` content is omitted from the rendered page but present in the Markdown an agent reads — useful for instructions that would be noise to a person.

<Visibility for="humans">
  <Note>You're reading the rendered site.</Note>
</Visibility>

<Visibility for="agents">
This block is written for AI agents reading the Markdown, and is omitted from the page.
</Visibility>

```mdx
<Visibility for="humans">
  <Note>You're reading the rendered site.</Note>
</Visibility>

<Visibility for="agents">
This block is written for AI agents reading the Markdown, and is omitted from the page.
</Visibility>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `for` | `string` | — | `humans` or `agents`. |
