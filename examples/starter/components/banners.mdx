---
title: "Banners"
description: "A prominent, optionally dismissible announcement."
---

Use a banner for something the reader should see before the page content — a migration notice, an outage, a version warning.

<Banner type="info" dismissible>
  A prominent announcement. Use `type="warning"` or `type="critical"` to raise the volume.
</Banner>

```mdx
<Banner type="info" dismissible>
  A prominent announcement. Use `type="warning"` or `type="critical"` to raise the volume.
</Banner>
```

For a notice on *every* page, set `banner` in `docs.json` instead — it renders above the
navbar site-wide:

```json docs.json
"banner": {
  "content": "Version 2.0 is live. See the [changelog](/changelog).",
  "dismissible": true
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `string` | `info` | `info`, `warning` or `critical`. |
| `dismissible` | `boolean` | `false` | Show a close button. |
| `content` | `ReactNode` | — | Alternative to children. |
| `color` | `string \| { light, dark }` | — | Override the background. |
