---
title: "Steps"
description: "Numbered, ordered instructions."
---

Steps are for a sequence that must happen in order. If order doesn't matter, a list is clearer.

<Steps>
  <Step title="First">Numbered, ordered instructions.</Step>
  <Step title="Second">Each step can hold any content, including code.</Step>
</Steps>

```mdx
<Steps>
  <Step title="First">Numbered, ordered instructions.</Step>
  <Step title="Second">Each step can hold any content, including code.</Step>
</Steps>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` | — | On `<Step>`: the step heading. |
