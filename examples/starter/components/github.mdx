---
title: "GitHub"
description: "A repository card."
---

`<GitHub.Repo>` renders a link card for a repository.

<GitHub.Repo repo="papervine/starter" />

```mdx
<GitHub.Repo repo="papervine/starter" />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `repo` | `string` | required | `owner/name`. |
| `variant` | `"inset" \| "flat"` | `inset` | Card styling. |
